Plume 0.6.0 : code source, Ubuntu et première version Windows.

- **Windows 10/11 x64** : `Plume-0.6.0-windows-x64.exe`, installateur pour l’utilisateur courant, avec GTK et les composants audio.
- **Ubuntu 24.04 x64** : `plume_0.6.0_amd64.deb`. Installation : `sudo apt install ./plume_0.6.0_amd64.deb`.
- **Code source** : `Plume-0.6.0-source.zip` (ou le lien GitHub « Source code (zip) »).
- **Source correspondant à Spotifyd** : archive complémentaire avec dépendances Rust, nécessaire pour reconstruire le composant GPL fourni sous Linux.
- **Empreintes** : `SHA256SUMS.txt`.

Spotify Premium requis. Client indépendant, non affilié à Spotify. Les quotas Spotify peuvent empêcher temporairement une connexion ou un chargement.

Première version Windows expérimentale. Le démarrage de l’interface est vérifié automatiquement ; la connexion à un vrai compte, l’écoute et le transfert vers un téléphone restent à valider sur Windows. L’exécutable n’est pas signé avec un certificat éditeur. Le plafond strict de 300 Mo est disponible uniquement sous Linux ; Windows affiche sa consommation sans imposer ce plafond.
